# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you discover a vulnerability, please report it to us as soon as possible.

**Please DO NOT open a public issue.** Instead, send an email to `security@example.com` (replace with your actual security contact email).

In your report, please include:
- A clear description of the vulnerability.
- Steps to reproduce the vulnerability.
- The potential impact of the vulnerability.
- Any suggested mitigations or fixes.

We will acknowledge your report within 48 hours and provide a more detailed response within 5 business days. We appreciate your efforts to improve the security of our project.

## Supported Versions

We only provide security updates for the latest stable release. Users are encouraged to upgrade to the latest version to ensure they have the most recent security patches.
